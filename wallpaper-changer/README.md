# ScrollWall — обои с прокруткой

Крошечное Android-приложение (Android 11+, без зависимостей): выбираешь картинку — она ставится
как обои, которые «едут» при перелистывании рабочих столов.

- Картинка масштабируется равномерно (cover): по высоте экрана, пропорции не меняются.
- Всё, что не влезло по ширине, раскладывается на все рабочие столы: первый экран — левый край,
  последний — правый. Число экранов учитывается само (лаунчер присылает смещение 0…1).
- Сделано как живые обои (`WallpaperService`): у обычных статичных обоев на современных
  прошивках прокрутку отключают, а тут она под нашим контролем.
- В системном превью картинка плавно катается сама, чтобы было видно эффект.

## Сборка

```bash
cd wallpaper-changer
echo "sdk.dir=/path/to/Android/Sdk" > local.properties
gradle assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17+, Gradle 8.9+, Android SDK platform 35. Либо просто открыть папку в Android Studio.

## Нюанс

Прокрутка зависит от лаунчера: он должен сообщать обоям смещение страниц (Pixel Launcher, Nova,
Lawnchair и большинство других это делают). Если лаунчер смещений не шлёт, картинка стоит по центру.
